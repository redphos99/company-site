# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページ完結のWebサイトです。社名、人物、数値、所在地はすべて架空のものです。

## 概要

「遠くまで見渡して、長く使えるソフトウェアを。」をコンセプトにした、コーポレートサイトのデモです。ビルの階層になぞらえた事業紹介や、夜明けの街並みのヒーローイラストが特徴です。

### 掲載セクション

| セクション | 内容 |
| --- | --- |
| ヘッダー・お知らせ欄 | ナビゲーションと、その直下に最新のお知らせを1件表示 |
| ヒーロー | キャッチコピー、街並みのイラスト、会社の数字（設立年・エンジニア数など） |
| 事業内容 | データ・AI活用、プロダクト開発、クラウド基盤、保守・運用を4F〜1Fの階層で紹介 |
| 進め方 | 課題整理から運用・改善までの4段階 |
| 実績 | 物流・医療・小売の3つの事例 |
| お知らせ | 直近のお知らせ一覧 |
| 会社情報 | 会社概要 |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 特徴

- HTML・CSS・JavaScriptを1ファイル（`index.html`）にまとめており、ビルド作業は不要です
- スマートフォンからデスクトップまで、画面幅に合わせてレイアウトが変わります
- OSの設定に応じて、ライトモードとダークモードが切り替わります
- 街並みのイラストはJavaScriptで生成しています

## ブラウザで開く手順

1. このリポジトリを手元に用意します（クローン、またはフォルダごとコピー）。
2. エクスプローラーで `index.html` を探します。
3. `index.html` をダブルクリックします。既定のブラウザで開きます。

特定のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウにファイルをドラッグ＆ドロップしてください。

### コマンドラインから開く場合

PowerShell で、このフォルダに移動して次を実行します。

```powershell
Invoke-Item .\index.html
```

macOS の場合は `open index.html`、Linux の場合は `xdg-open index.html` で開けます。

### 表示についての注意

- フォントは Google Fonts から読み込むため、初回の表示にはインターネット接続が必要です。オフラインでは代替フォントで表示されます。
- 動作確認は Microsoft Edge（Chromium）で行っています。日本語の折り返しに使う `word-break: auto-phrase` は、対応していないブラウザでは通常の折り返しになります。
